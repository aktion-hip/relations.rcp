# Relations

Source code for the Relations Application, based on Eclipse e4 RCP.

## Steps to build and create Mac DMG

- `git clone https://github.com/aktion-hip/relations.rcp.git`
- cd `relations.rcp`
- `git checkout mac-dmg`
- `mvn clean verify`
