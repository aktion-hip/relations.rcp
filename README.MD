# Relations

Source code for the Relations Application, based on Eclipse e4 RCP.

## Steps to build

- git clone
- cd `relations.rcp`
- `mvn clean verify`

Project page: [https://sourceforge.net/projects/relations-rcp/](https://sourceforge.net/projects/relations-rcp/)
