Peer-to-Peer: Firewall

For peer-to-peer uploads, the smartphone must be able to establish a connection with the computer.
In some cases, you may need to adjust the firewall on the computer to ensure that the port (e.g. 9042) for this connection is open.

Firewall Rule

For Windows PowerShell (Admin mode)

New-NetFirewallRule -DisplayName "Open for Relations.RCP" -Direction Inbound -Protocol TCP -LocalPort 9042 -Action Allow -Profile Private
